# ML Bootcamp Experiences

Jupyter notebooks and datasets from my machine learning bootcamp, covering:

- **Regression:** Simple/Multiple/Polynomial Linear Regression, Ridge/Lasso/ElasticNet, SVR, KNN, AdaBoost, Gradient Boosting, XGBoost, LightGBM
- **Classification:** Logistic Regression, SVM, Naive Bayes, KNN, Decision Tree, Random Forest, AdaBoost, Gradient Boosting, XGBoost, LightGBM
- **Unsupervised:** PCA, K-Means Clustering, Anomaly Detection
- **Other:** Feature scaling, Box-Cox / Yeo-Johnson transformations, saving models, House Price EDA & deployment

## Datasets

The CSV datasets used in the notebooks are not included in this repo. Most are public datasets (e.g. Kaggle, UCI).
